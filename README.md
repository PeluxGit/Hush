# Hush

Replaces select loud in-game alerts with quieter variants, with per-sound volume and output channel controls.

---

## Highlights

- Replaces specific loud alerts with custom OGG files at controlled volume levels.
- Per-sound enable/disable toggle.
- Per-sound volume selection: `100%`, `75%`, `50%`, `25%`.
- Per-sound output channel selection: `Master`, `SFX`, `Music`, `Ambience`, `Dialog`.
- Built-in **Test** button for each sound.

---

## Sounds Covered

- Ready Check
  - This sound is used when a **Ready Check** is initiated or when a **Dungeon Finder** or **Raid Finder** prompt is ready.
- PvP Through Queue
  - This sound is used when a **Battleground** or **Arena** queue is ready.
- PvP Enter Queue
  - This sound is used when joining a **Battleground** or **Arena** queue.
- LFG Denied
  - This sound is heard when someone declines a **Dungeon Finder** or **Raid Finder** prompt.

---

## Configure

`Game Menu -> Options -> AddOns -> Hush`

For each sound, you can:

- Enable or disable replacement.
- Choose replacement volume.
- Choose output channel.
- Click **Test** to preview the replacement immediately.

---

## Install

1. Download the release zip.
2. Extract to:

```text
World of Warcraft/_retail_/Interface/AddOns/Hush
```

3. Restart WoW or run `/reload`.
