# Changelog

## [2026-02-14]

### Initial release

- Added replacement handling for select loud alerts: Ready Check, PvP Through Queue, PvP Enter Queue, and LFG Denied.
- Added per-sound enable/disable toggles.
- Added per-sound volume controls (`100%`, `75%`, `50%`, `25%`).
- Added per-sound output channel controls (`Master`, `SFX`, `Music`, `Ambience`, `Dialog`).
- Added in-options **Test** buttons to preview each replacement sound.
- Added SavedVariables persistence via `HushDB`.
